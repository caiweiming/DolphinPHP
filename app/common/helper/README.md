# Helper 工具类目录

此目录包含 DolphinPHP 框架的各种助手工具类。

## 可用工具类

### TreeBuilder - 树形结构构建器

通用的树形结构构建工具,可以将一维数组转换为树形结构。

**核心特性:**
- ✅ 自定义字段名(主键、父级ID、子级字段名)
- ✅ 自定义根节点父级ID值
- ✅ 自动添加层级信息
- ✅ 自动生成ID路径和名称路径
- ✅ 支持排序
- ✅ 扁平化树形数据
- ✅ 丰富的静态工具方法

**快速开始:**

```php
// 基础用法
$tree = dp_build_tree($data);

// 自定义配置
$tree = dp_tree_builder($data)
    ->setIdField('id')
    ->setParentField('parent_id')
    ->withLevel('level')
    ->withPath('path', '/')
    ->build();
```

**文档:**
- [TreeBuilder 快速入门](../../../docs/TreeBuilder快速入门.md)
- [TreeBuilder 使用指南](../../../docs/TreeBuilder使用指南.md)

**测试示例:**
- [测试文件](../../../test/tree_builder_test.php)

**适用场景:**
- 部门管理
- 菜单管理
- 分类管理
- 区域选择
- 评论系统
- 任何需要树形结构的场景

### Logger - 轻量级日志记录器

用于记录应用程序日志的工具类。

**快速使用:**

```php
// 基础日志
dp_log('用户登录')->info();

// 带上下文的日志
dp_log('订单创建')
    ->context(['order_id' => 123])
    ->success();

// 记录异常
dp_log_exception($exception, '文件上传');
```

**文档:**
- 参见 `app/common.php` 中的日志助手函数

## 添加新的工具类

如果您需要创建新的工具类,请遵循以下规范:

1. **命名规范**: 使用大驼峰命名法,类名要清晰表达功能
2. **命名空间**: `namespace app\common\helper;`
3. **文件位置**: 放在此目录下
4. **助手函数**: 在 `app/common.php` 中添加对应的助手函数
5. **文档**: 创建使用文档和示例
6. **更新此文件**: 在本 README 中添加工具类说明

## 设计原则

工具类应该遵循以下设计原则:

- **单一职责**: 每个工具类专注解决一个问题
- **易于使用**: 提供简洁的 API 和助手函数
- **高性能**: 注重性能优化
- **可配置**: 支持灵活的配置选项
- **文档完善**: 提供详细的使用文档和示例
- **通用性**: 设计为通用工具,不耦合业务逻辑

## 与框架集成

所有工具类都可以通过以下方式使用:

1. **直接使用类**: `TreeBuilder::make($data)->build()`
2. **助手函数**: `dp_build_tree($data)`
3. **依赖注入**: 在需要的地方注入使用

选择最适合您使用场景的方式即可。
